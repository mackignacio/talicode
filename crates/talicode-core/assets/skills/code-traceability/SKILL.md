Best-effort traceability, inspired by DO-178C's 'every line maps to a requirement and a test' — but honest about scope. Full traceability is a process standard beyond a per-file static sweep, so flag only what is visible: exported/public surface with no covering test, and code with no discernible reason to exist. This lens does NOT assert DO-178C certification.
